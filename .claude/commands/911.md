# 911 — Quick cheatsheet

> Forgot a command? Start here. Need full list? `/911-full`.

## 🟢 Daily 4 (memorize)

| Command | One-liner |
|---|---|
| `/todo add <description>` | Spec-first task with grill-me + Diablo gates |
| `/orchestrate` | Autonomous backlog: test-writer → tests → review → Diablo → commit |
| `/general <question>` | Verified Q&A, evidence-first, no speculation |
| `/rule <statement>` | Capture business rule (rate / fee / formula) into docs/RULES.md |

## 🔵 Decision tree

```
Want to know something          → /general
Found a bug                      → /fix
Is a new idea worth building?    → /market-research → /value-prop   (validate first)
Have a goal, no spec (deep)      → /design-system → /decompose
Have a vague idea (quick)        → /intent → /decompose
Have a written spec / TZ         → /analyze-spec → /decompose
Segment + value settled          → /product-requirements → /decompose
Existing product, what next?     → /diagnose
Have one specific task           → /todo add → /orchestrate
Want to ship something           → /orchestrate
Need a sanity check              → /gaps          (asks: what to check)
Are the tests actually any good?  → /gaps          (pick "tests": do tests catch bugs; needs NO docs)
Numbers / reports look wrong      → /gaps          (pick "domain": correctness + robustness)
Audit whole service, every angle → /global-audit  (11 parallel lenses, FMEA-ranked)
Code feels wrong                 → /improve-arch
Just deployed — check prod ok?   → /canary <production_url>
Building API/CLI/SDK for devs    → /plan-devex-review
Forgot a command                 → /911-full (FULL cheatsheet)
```

> **Многие команды теперь спрашивают.** Забыл режим/флаг — просто введи голую команду
> (`/gaps`, `/global-audit`, `/docs`, `/da`), и она сама покажет меню. Синтаксис помнить не нужно.

> **Greenfield (idea → build)** chains front-to-back: `/market-research → /value-prop → /design-system → /decompose → /orchestrate`. Full contract: `docs/rules-references/greenfield-pipeline.md`.
