# FAILS — Known Failure Patterns (index)

> **Format rules:**
> - One lesson = one file in `docs/fails/F-NNN-<slug>.md`; ID = file name; first line of the file = one-line summary (symptom → cause).
> - Before adding: grep this index for an existing lesson about the same cause — if found, UPDATE that file instead of creating a duplicate. Next free NNN = max across `docs/fails/` file names AND this index.
> - A disproven lesson is DELETED — remove the file together with its index line. Wrong memory is worse than no memory.
> - Keep the index sorted by number. Consistency checked by `bin/memory-lint.sh` (duplicate IDs, placeholders, orphans).
