# PATTERNS — Established Solutions Registry (index)

> **Format rules:**
> - One pattern = one file in `docs/patterns/P-NNN-<slug>.md`; ID = file name; first line of the file = one-line summary (problem → solution).
> - Before adding: grep this index for an existing pattern solving the same problem — if found, UPDATE that file instead of creating a duplicate. Next free NNN = max across `docs/patterns/` file names AND this index.
> - A disproven/superseded pattern is DELETED — remove the file together with its index line. Wrong memory is worse than no memory.
> - Keep the index sorted by number. Consistency checked by `bin/memory-lint.sh` (duplicate IDs, placeholders, orphans).
> - Legacy note: entries formerly used `PAT-NNN` IDs — renamed to `P-NNN` in this format.
